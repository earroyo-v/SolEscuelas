Objetivo: 
Evaluar las habilidades del desarrollador en la implementación de un sistema básico.
 
Prueba Técnica: 
Desarrollar una aplicación que permita:
1.	Gestión de Escuelas de Música: 
•	Crear, Actualizar y Eliminar Escuelas.
•	Cada Escuela debe tener un nombre, descripción y un código único. 

2.	Gestión de Escuelas y Profesores y Alumnos: 
•	Crear, Actualizar y Eliminar Escuelas, Alumnos y profesores. 
•	Cada alumno debe tener un nombre, apellido, fecha de nacimiento, y un número de identificación único.
•	Cada profesor debe tener un nombre, apellido, y un número de identificación único.

3.	Asignación de Profesores a Escuelas y Alumnos a Profesores.
•	Asignar N Alumnos a un profesor.
•	Un profesor puede impartir a múltiples alumnos, pero un Profesor solo puede ser asignado a una escuela.

4.	Inscripción de Alumnos a Escuelas:
•	Inscribir un alumno a una Escuela. 
•	Un alumno puede estar inscrito con múltiples Profesores. 

5.	Consultas:
•	Consultar alumnos que estén inscritos por profesor y mostrar a que escuela pertenece. 
•	Consultar todos los Escuelas que imparte un profesor y los alumnos inscritos. 

6.	Stored Procedures: 
•	Crear un stored procedure para manejo del CRUD de cada entidad (Escuelas, Alumnos, Profesores). 

Requerimientos técnicos: 
•	El sistema debe estar desarrollado en el lenguaje de tu preferencia (NetCore, .Net)
•	Uso de base de datos SQL Server
•	Implementar una API REST para manejar las operaciones CRUD y las consultas.
•	Versionar en repositorio GitHub.
